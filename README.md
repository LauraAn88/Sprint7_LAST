# Sprint7_LAST
Proyecto sprint 7

URL Render: https://sprint7-last.onrender.com

El proyecto de sprint 7 tiene cómo finalidad explotar los conocimientos adquiridos hasta ahora:
- Limpieza de datos en python:
    Se utilizan librería pandas pandas la lectura, limpieza y exploración de información.
    Librería plotly para la visualización de gráficos
    Y streamlit para la conversión en aplicativos web 
- Herramientas github para el versionamiento de los proyectos y el alcance web
    Se utiliza para el versionamiento de los proyectos y la conexión con render
- Manejo de aplicativos para productivizar aplicativos web
    Render es una herramienta que te permite lanzar el aplicativo web 

El resultado de este proyecto es utilizar las herramientas mencionados anteriormente para visualizar en la web un aplicativo que te permite explorar dos gráficos del insumo vehicules.
